# 指纹考勤系统上位机

这是一个基于 Qt 6 的桌面上位机，用于通过 TCP 与 ESP8266 通信，并由 ESP8266 透明转发数据至 STM32 指纹考勤终端。

上位机负责显示终端当前工作模式、记录指纹录入/验证过程、同步 AS608 指纹库索引，并维护指纹 ID 对应的人员信息。

## 功能

- TCP 客户端连接 ESP8266 的 TCP 服务。
- 显示 STM32 上报的当前工作模式：验证模式或录入模式。
- 发送工作模式切换命令。
- 显示录入和验证过程日志。
- 接收 1024 位指纹索引表，并显示 AS608 中的已录入指纹数量。
- 使用 SQLite 保存指纹 ID 与人员资料，并在表格中直接编辑资料。
- 在表格中右键删除人员记录，同时向下位机发送删除对应指纹的命令。

## 运行环境

- Qt 6.5 或更高版本
- Qt 模块：Core、Widgets、Network、Sql
- CMake 3.19 或更高版本
- 支持 C++ 的编译器（Windows 下可使用 MSVC 或 MinGW）

## 构建与运行

在本项目根目录执行：

```bash
cmake -S . -B build
cmake --build build --config Release
```

运行生成的 `Attendance_System` 程序。首次运行时，程序会在当前工作目录创建 SQLite 数据库文件 `information.db`。

## 连接设备

1. 让电脑与 ESP8266 连接到同一个局域网。
2. 确认 ESP8266 已连接到路由器，并记录其 IP 地址。
3. 打开上位机，在 `Address` 中填写 ESP8266 的 IP 地址。
4. 在 `Port` 中填写 ESP8266 的 TCP 端口，当前配套固件默认使用 `8080`。
5. 点击 `Connect`。连接成功后会显示设备连接成功提示。
6. 点击“切换工作模式”，等待下位机回传模式状态；按钮在等待回包期间会置灰，收到状态包后会恢复可用。

## 通信架构

```text
Qt 上位机  <-- TCP -->  ESP8266  <-- UART 115200, 8N1 -->  STM32  <-- UART -->  AS608
```

ESP8266 的 UART 串口必须与 STM32 的 USART3 使用相同参数：115200 波特率、8 数据位、无校验、1 停止位。

## 自定义协议

数据帧格式如下：

```text
0x5A 0xBB | CMD | LEN | DATA... | 0x3B 0x4F
```

- `CMD`：1 字节命令字。
- `LEN`：1 字节数据长度。
- `DATA`：长度为 `LEN` 的可选数据。

TCP 是字节流，不保证一次收到完整帧；上位机的 `Protocol` 类会缓存数据，并处理拆包、粘包和帧头截断。

### 主要命令

| 方向 | 命令 | 含义 | 数据 |
| --- | --- | --- | --- |
| STM32 → 上位机 | `0xA1` | 当前为验证模式 | 无 |
| STM32 → 上位机 | `0xA2` | 当前为录入模式 | 无 |
| STM32 → 上位机 | `0xA3` | 更新指纹索引表 | 128 字节，共 1024 位 |
| 上位机 → STM32 | `0xB1` | 切换工作模式 | 无 |
| 上位机 → STM32 | `0xB2` | 删除指纹 | 2 字节大端序指纹 ID |
| STM32 → 上位机 | `0xA6` | 删除指纹失败 | 无 |
| STM32 → 上位机 | `0xA7` | 删除指纹成功 | 无 |

录入过程使用 `0xC1` 至 `0xCB` 及对应失败码；验证过程使用 `0xE1` 至 `0xE9`。上位机收到这些命令后会在右侧日志框显示过程信息。

## 数据库

数据库文件为 `information.db`，表名为 `information`，主要字段如下：

| 字段 | 含义 |
| --- | --- |
| `id` | 学号 |
| `name` | 姓名 |
| `age` | 年龄 |
| `sex` | 性别 |
| `class` | 班级 |
| `email` | 邮箱 |
| `finger_id` | AS608 指纹 ID，唯一 |

收到指纹索引表后，上位机会为尚未存在的指纹 ID 自动建立空白记录。表格中编辑后的内容会自动写入 SQLite。

## 使用注意

- ESP8266 的 TCP 服务端口必须与上位机输入的端口一致。
- ESP8266 与 STM32 的 UART 必须交叉连接：ESP TX → STM32 RX，ESP RX ← STM32 TX，并共地。
- ESP8266 的 UART 同时承担协议转发时，不应向该串口输出调试文字，否则会破坏协议帧。
- 模式切换按钮在收到 `0xA1` 或 `0xA2` 前会保持禁用；若长期置灰，应检查 TCP 连接、ESP8266 转发和 STM32 串口收发。
